## 📖 Overview

My personal portfolio — built to showcase who I am, what I build, and how I think. It runs on a dark, premium aesthetic with smooth motion design, a 3D interactive avatar, and a physics-based tech stack visualizer.

The site is organized around two core focus areas:

| Focus Area | What It Covers |
|---|---|
| 🤖 **AI & Automation** | Helping teams automate internal ops and customer-facing workflows so they ship faster with less manual work |
| 🏗️ **Build & Scale** | Production-ready systems — APIs, data pipelines, voice/real-time apps, and full-stack products |

## ⚡ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Crusty-chirayu/portfolio.git

# Navigate into the project
cd portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
