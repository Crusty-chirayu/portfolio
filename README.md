## About

My personal portfolio website — built to showcase who I am, what I build, and how I think. It features smooth animations, 3D interactive elements, and a dark cyberpunk aesthetic.

The site highlights two core focus areas:

**AI & Automation** — helping organizations automate workflows (internal ops and customer-facing) so teams ship faster with less manual work.

**Build & Scale** — shipping production-ready systems: APIs, data pipelines, voice/real-time apps, and full-stack products.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Crusty-chirayu/portfolio.git

# Navigate into the project
cd portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
